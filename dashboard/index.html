Reads directly from api.github.com, unauthenticated - no backend of its own. Same metrics as scripts/health-report.js's weekly pinned issue, live in your browser instead of a 7-day-old snapshot. Hub Health reads this repo's own Actions run history for its four scheduled workflows (self-reflect, health-report, recursive-learning, prune-logs) - ci.yml is left out on purpose, since it's a PR/push code-quality gate, not a scheduled operational signal. Unauthenticated GitHub API calls are capped at 60 requests/hour per IP - a "rate-limited" status below means the cap was hit, not that anything is actually wrong. A status labeled "offline - last seen ..." means this page couldn't reach GitHub at all and is showing the last real data it saw, however old that is.

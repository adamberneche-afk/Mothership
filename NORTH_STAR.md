# Project North Star

## Core Benefit
Mothership centralizes the AI-assisted code review logic ("debug", "hunt", "refactor" audits) that would otherwise need to be duplicated into every individual project repo ("spoke"). One deployment, one set of standards, one API key - every spoke stays lean and only needs a heartbeat workflow.

## Emotional Outcome
Maintainers should trust that anything this system posts as a GitHub issue is grounded in a real, current diff - not a plausible-sounding guess. If there's nothing real to report, it should say nothing, not manufacture a finding to justify the run.
